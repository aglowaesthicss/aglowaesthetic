# Lovable Hub

3 roles Master Admin Owner and Founder has complete access, Front Office Feeding Client details -ClientID,Name,Mobile No. Age, EMail ID, Location , Invoice , session tracking of client, Only Master Admin can create Staff. Master Admin and Staff can create Client, Master Admin can Create Master Admin

Let each user reset their password in settings.

Master Admin can Update Master Admin,Staff, Client Password anytime 

7 Features 

Service History - Details about the clients previous service taken and the invoice of the service . Client can view the service history . Head Admin Add, Update and delete the History  and Front office can Add, Update, the History.

Session Tracking - Client can see when is there next service. Head Admin can Add, Update , Delete the Session, and Front Office can Add Update the session. Like they can select the service from the list of services and add dates , and time for each date. 

Services- service name with image and description , the price will be updated later . The client can view and Head Admin can Add,Update,Delete it

Offers - Normal offers and Special Offers can be viewed and apply by the client and Add,Update , Delete it, and also they can fix the start and end date. After the end date the offer should be hidden to client . and also special offer will be pinned in top in services section as well. 

Feedback and Complaints- Within that the client can select Feedback or complaint and then fill it the details. The Head Admin can view the Feedback and Complaints with customer details and response back to them 

Location - The Branch Location with Google maps will be viewed by the client, Head Admin can Add,Update,Delete it 

Testimonial  - With instagram, Youtube and Text, Image contents, Viewed by clients and Head Admin can Add,Update,Delete it.

Access Control - Provide a Access Control in Master Admin where they can add,update or revoke acces to features to any role except Master Admin




We also need to send email when we add any special offer or offer to client, and also when client is added into the System the user name and password should be sent to them , and on the session day they should get a email that they have their session today with time of the session. 

We are using Render for backend, Vercel for frontend , MongoDB for db, Cloudinary for images, Resend for email. Use Python for backend 




The Public can view Home , About us, Services , Offers, Location,Testimonial . also they will have a Enquiry now form where it gets , Client Name, Email,Phone , Location, Service . 




Also there is a chatbot which can be used to chat with user about the service , location , working days and time , using rag and llm .
